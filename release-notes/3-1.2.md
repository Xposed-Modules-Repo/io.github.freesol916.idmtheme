## 1DM+ 动态配色 1.2

### 新增

- **曲率指数滑块**：圆角不再固定为 G2。指数 `n` 可在 **2.0–8.0** 之间调，
  `n = 4` 是 G2 超椭圆，`n = 2` 退化成普通圆弧，越大越接近方形。半径仍为 0–48dp（默认 24dp）。
- **AMOLED 纯黑**：深色模式下把 `surface` / `surface_low` 压到 `#000000`、卡片与弹窗压到 `#101010`，
  主界面纯黑省电，同时保留卡片层次。
- **深色模式适配**：跟随系统深浅色，语义令牌自动切到 `_dark` 一组；
  列表行、Tab 条等「品牌色当底色」的位置在深色下改用 `surface_container_low`，
  不会再出现浅色块压深色文字的情况。

### 兼容

- **API 29–30 / 31–33 兜底**：语义令牌（`system_primary_light` 这批）是 Android 14 才有的。
  现在 API 31–33 会自动改用 `system_accent1_*` / `system_neutral1|2_*` tonal 令牌合成角色配色；
  API 29–30 退回 Material 基线配色。低版本不再出现「取不到色 → 整片原版青绿」。
- **抗资源漂移**：角色判断改为**名字优先**，资源 ID 表只作兜底；两者冲突时以名字为准，
  并打一条 `resource drift on 0x…` 日志。1DM+ 升级后 ID 变动不会让整套映射静默失效。

### 修复

- 深色模式下列表行底色被误判成强调色（浅蓝紫）的问题。
- 模块设置里改动 `AMOLED` / 曲率指数后，配置未能完整推送到目标进程的问题。

### 安装

1. 安装 APK，在 LSPosed 里启用模块（作用域已固定为 1DM+）。
2. 强制停止 1DM+ 再打开。
3. 需要自定义就打开桌面上的 **1DM+ M3 Expressive Theme**：选颜色、拖半径与曲率滑块、按需开 AMOLED，
   然后点 **保存并应用**。

- 要求：Android 10+（minSdk 29），LSPosed 支持 LibXposed API 102。
- 实测设备：OnePlus PJD110 / Android 17，1DM+ 18.2（versionCode 30249）。

## English

### Added

- **Curvature exponent slider**: the corner is no longer locked to G2. `n` can be set from **2.0 to 8.0**
  (`n = 4` is the G2 superellipse, `n = 2` degenerates into a circular arc, larger values approach a square).
  Radius stays adjustable from 0–48 dp (default 24 dp).
- **AMOLED black**: in dark mode `surface` / `surface_low` are forced to `#000000` and cards/dialogs to
  `#101010` — a true-black UI that still keeps card layering.
- **Dark-mode polish**: follows the system light/dark setting; places that use a brand color as a large
  background (list rows, tab strip) now map to `surface_container_low` in dark mode instead of a pale accent.

### Compatibility

- **API 29–33 fallbacks**: the semantic tokens only exist on Android 14+. API 31–33 now synthesizes roles
  from the `system_accent1_*` / `system_neutral1|2_*` tonal tokens; API 29–30 falls back to the Material
  baseline palette.
- **Resource-drift resistance**: role detection is name-first with the resource-ID table as a fallback,
  so a 1DM+ update that shifts IDs no longer breaks the mapping silently.

### Fixed

- List rows turned into a pale accent color in dark mode.
- AMOLED / curvature changes from the settings screen not reaching the target process reliably.
